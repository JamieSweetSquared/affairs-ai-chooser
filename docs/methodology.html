Methodology

How this free GitHub Pages MVP ranks four named tools — and what it does not claim.

Scope

Cycle-1 always returns the same four slots: Kit (email for creators), Leadpages (landing pages), Surfer (SEO / AI content visibility), and systeme.io (funnel / email / all-in-one). The quiz reorders those four. It does not search a wider catalog.

Quiz weights

Each tool starts at score 0. We add points from your three answers, then sort high → low. Ties keep the default order Kit → Leadpages → Surfer → systeme.io.

Budget (only where a vendor publishes a clear signal)

  • Free / freemium: Kit +2 (Kit publishes a free plan). systeme.io +2 (permanently free plan published). Leadpages 0 (site lists paid plans from $99/mo). Surfer 0 (no free-plan claim cited here).
  • Starter (~$20–50/mo): Kit +2. systeme.io +2 (Startup cited ~$17/mo). Leadpages 0 (published starting price sits above this band). Surfer 0 (price not cited on this page).
  • Team (~$50–200/mo): Leadpages +2 (published $99/mo Grow plan falls in-band). Kit +1, Surfer +1, systeme.io +1.
  • Enterprise: Surfer +2 (markets to agencies and enterprises). Leadpages +1. Kit 0 and systeme.io 0 (creator / entrepreneur positioning).

Team size

  • Solo: Kit +2 and systeme.io +2 (creator / solopreneur positioning). Leadpages +1, Surfer +1.
  • Small (2–10): Kit +2, Leadpages +2, systeme.io +2, Surfer +1.
  • Mid (11–50): Surfer +2 and Leadpages +2. Kit +1, systeme.io +1.
  • Large (50+): Surfer +2 and Leadpages +2 (agencies / content / campaign teams). Kit +1, systeme.io 0.
